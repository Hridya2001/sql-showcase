# SQL Showcase

This repository contains a curated collection of SQL scripts simulating a real-world employee management system. It demonstrates practical database operations including:

-  Table creation for employees, departments, and attendance
-  Insertion of realistic sample data
-  Queries using `JOIN`, `GROUP BY`, `CASE`, `SUBQUERIES`, and `VIEWS`
-  Schema modifications and indexing
-  Data updates and deletions

---

###  Why This Repo?

This repo was created with two main goals in mind:

1. **To demonstrate real-world SQL proficiency** through structured, readable, and relevant queries.
2. **To ensure that SQL is visibly represented in GitHub's top-languages chart (top-langs card)** by increasing SQL file size and content volume.

---

###  Ideal For:

- Practicing SQL fundamentals and intermediate skills
- Interview preparation
- Adding credible SQL contributions to your GitHub profile
